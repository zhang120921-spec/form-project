# FORM — 产品功能简介

*面向高尔夫教练与球友的通俗版功能说明。更新日期：2026-08-15*

---

## 一、项目概述

**FORM** 是一款面向私密好友圈子的高尔夫评分 App。核心玩法很简单：

> 每次打完一场球，系统根据你和对手的实际表现，自动更新每个人的"竞技分"（Rating）——打得好加分，打得差减分，真实反映大家当前的水平。

- 评分机制借鉴国际通用的 **Elo 算法**（国际象棋、电竞都在用），并针对高尔夫做了**差点（Handicap）修正**：低差点选手赢高差点选手，加分更少；反之爆冷，加分更多。
- 朋友之间打完球要**互相确认成绩**，杜绝乱报分；系统自动计算排名、胜率、连胜等数据。
- 核心卖点：**无法"打假球"**。因为评分始终与实际成绩挂钩，故意打差只会让评分下滑，反而暴露真实水平。

## 二、各页面功能

### 登录 / 注册
- 注册时填写：姓名、邮箱、所属球会、差点（支持 + 差点）
- 填差点时**实时预览**你的初始竞技分

### 首页（总览）
- 我的当前评分、排名、近期状态条（胜/负/平）
- **评分走势图**（鼠标悬停查看每场评分）
- 一键生成"我的评分"分享卡片
- 待确认成绩的提醒
- 与最佳对手的"宿敌卡"：交手记录、连胜纪录、胜率预测
- 排行榜前三名展示
- **AI 推荐下一个该和谁打**，可直接发起约球邀请
- 最近球局列表，每场可展开查看"评分是怎么算出来的"
- 数据概览：总场数、差点、信心度、胜率

### 排行榜
- 三个标签页：**好友榜 / 全球公开榜 / 职业球员榜**
- 全球榜支持按姓名、球会、地区搜索

### 球局记录
- 时间线展示所有打过的球局
- 展开查看每场详情：赛前/赛后评分、评分变化、参赛球员
- 每场都可以查看"评分计算过程"

### 记成绩
- **拍照自动识别记分卡**（AI 识别，不用手输）
- 语音录入成绩
- 手动填写 / 快速录入
- 支持多种赛制：比杆赛、史特伯福（Stableford）、比洞赛

### 我的主页
- 个人资料卡（头像、姓名、球会、地区）
- 评分、排名、近期状态条
- 数据统计：总场数、差点、信心度、胜率
- 分享评分卡片
- **赛季总结**：赛季峰值/低谷、最佳/最差成绩、最常打的球场、对战数据，自动生成图文总结，一键复制分享
- "是否出现在全球排行榜"开关（隐私控制）
- **成绩确认中心**：好友提交的球局需要你确认或申诉（申诉时可修改成绩）
- 宿敌详情：最长连胜、最大分差、近 5 次交手记录
- 交手多样性：提醒你是否总在和同一批人打球

### 好友
- 好友列表：显示交手热度，可给"常打球友"标星 ★
- 收到的约球邀请：接受 / 拒绝
- 收到的好友申请：接受 / 拒绝
- 搜索球友并发起好友申请（可附留言）
- 查看自己的"交手多样性"提醒

### 球员主页（他人）
- 查看其他球员的公开资料：评分、差点、状态徽章
- 一键"加为好友"

### 防作弊（为什么不能打假球）
- 科普页面：通俗解释为什么 FORM 评分无法被操纵
- **互动模拟器**：对比"故意打差"和"正常发挥"两条路，评分和差点分别会变成什么样

### 公平让杆
- 选择 2–4 名球员、球场、发球台、赛制，系统自动计算**让杆数**（可手动微调）
- 估算每位球员的胜率
- 自动生成一段可以直接转发的约战说明（带让杆方案）
- "对比职业球员"：看你的评分排在职业球员的什么位置

## 三、特色功能（增值）

### AI 能力
- **球局解说**：把一场球的数据用自然语言讲出来（"Mike 前九洞……"）
- **记分卡拍照识别**：拍张照片自动录入成绩
- **自然语言记成绩**：直接输入"周三和 Mike 打了 82 杆"，系统自动解析
- **推荐对手 + 异常成绩检测**：帮你约合适的对手，同时识别可疑的"刷分"成绩
- **赛季总结**：自动生成图文并茂的赛季回顾
- （管理员专属）AI 辅助更新职业球员数据

### 后台管理（管理员）
- 管理后台页面：用户管理、球场管理、系统参数、数据重算、服务器重启/关闭
- 管理员命令行工具：预设命令一键执行，实时查看输出

### 技术底座（给懂技术的人看）
- 安全登录：JWT + 密码加密存储，登录限流，支持找回密码
- 动态评分引擎：Elo 算法 + 差点修正 + WHS 差点跟踪
- 单文件离线版本：支持不联网使用
